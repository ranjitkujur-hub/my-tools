# my-tools

Three small, private web tools that run entirely in the browser (no server, no sign-in; data stays on your device). Open `index.html` or the GitHub Pages site.

| Tool | Folder | What it does |
|------|--------|--------------|
| पत्र निर्माता / Letter Maker | [`letter-maker/`](letter-maker/) | Write official Hindi letters with a live A4 preview; print/PDF, download Word (Unicode or Kruti Dev), Unicode ⇄ Kruti Dev converter. |
| पत्र पंजी एवं घटनाक्रम / Letter Register & Chronology | [`letter-register/`](letter-register/) | Register of incoming/outgoing letters and datewise chronologies. |
| किडनी स्वास्थ्य रिकॉर्ड / Kidney Health Tracker | [`health-tracker/`](health-tracker/) | Record blood tests, medicines and doctor visits; see trends. |

Each tool is plain HTML/CSS/JavaScript with no build step. Developer files (tests, `package.json`) live inside each tool's folder.
